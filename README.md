# متجر عبايات الخولي | EL-KHOLY ABAYAS 👑🧕

متجر إلكتروني متكامل وفاخر متخصص في **العبايات الحريمي والخليجي والسواريه والإسدالات** لصاحبه **الخولي**، مبني كـ Full-Stack Web Application باستخدام **Python (Flask)** و **SQLite** وواجهة عربية عصرية أنيقة بـ **Tailwind CSS**.

---

## 🌟 الهوية والاسم التجاري
- **اسم البراند:** عبايات الخولي | EL-KHOLY ABAYAS
- **الشعار:** حرف «خ» الذهبي الفاخر
- **العملة المعتمدة:** الجنيه المصري (ج.م)
- **كود الخصم الترويجي:** `KHOLY20` (خصم 20% للعميلات)
- **الشحن:** شحن مجاني للطلبات فوق 1,000 ج.م

---

## 🛍️ أقسام المتجر:
1. **عبايات خروج وكاجوال:** (كريب صالونا، كريب ندى، كريب سعودي، عملية وباردة للدوام والمشاوير).
2. **عبايات سواريه ومناسبات:** (مخمل ملكي، حرير مغسول، شك يدوي وتطريز كمبيوتر للمناسبات والأفراح).
3. **عبايات خليجي وبشت:** (قصات كلوش وبشت إماراتي واسع مع أندر دريس منفصل).
4. **إسدالات واستقبال:** (إسدالات صلاة قطن طبيعي 100% وقفاطين استقبال بيتي راقية).
5. **طرح وشيلات ونقابات:** (شيفون كوري دبل فيس ونقاب حرير مريح).

---
